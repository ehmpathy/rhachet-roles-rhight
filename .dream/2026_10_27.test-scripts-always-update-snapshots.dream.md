# 🌙 dream: the test scripts pass --updateSnapshot on every run, so no snapshot can ever fail

kind: defect · owner: rhachet-roles-rhight (and the declapract template that stamps these scripts — reseed) · caught 2026-10-27

## .the cue that fired

a red-proof run of the pii clamp (cure reverted, no `--resnap`) reported `Snapshots: 3 updated` and rewrote the snapshot file with the WRONG output. a failed assertion should never write a snapshot.

## .the gap, precisely

`package.json` scripts `test:unit`, `test:integration`, `test:acceptance`, `test:acceptance:locally` each end with

    $([ -n $RESNAP ] && echo '--updateSnapshot')

with `RESNAP` unset, the unquoted expansion leaves `[ -n ]` — one non-empty argument, which is TRUE. so `--updateSnapshot` rides on every run, local and CI. every `toMatchSnapshot()` in the repo is a write, never a check. (`[ -z $THOROUGH ]` is right only by the same accident: `[ -z ]` is also true.)

checkable: `bash -c 'unset RESNAP; echo "[$([ -n $RESNAP ] && echo yes)]"'` prints `[yes]`.

## .the shape of the fix

1. quote both: `[ -n \"$RESNAP\" ]`, `[ -z \"$THOROUGH\" ]` in the four scripts (+ `test:integration:hold`). verified: unset → no flag; `RESNAP=true` → flag.
2. the moment (1) lands, snapshots that were never deterministic go red. found so far (integration, pii-adjacent scope only):
   - `patent.propose.integration.test.ts` :62, :94 — embed the route date `v2026_MM_DD` and a `/tmp/test-fns/<repo>/.temp/<iso>.<uuid>/` path
   - `transcribe.pdf.integration.test.ts` :144, :205 — embed `.temp/genTempDir.symlink/<iso>.<uuid>/` paths
   - 1 obsolete snapshot in one of those suites
   mask each (date → `vYYYY_MM_DD`, temp root → `<tmp>`) before snapshot, then re-run unit + integration + acceptance `--thorough` and mask whatever else surfaces.
3. reseed to the declapract template that stamps these scripts, so every ehmpathy repo gets the quote.

## .why it is not done in this round

SAFE: yes. CLEAN: no — the quote fix is one line, but it turns latent nondeterminism in other roles' tests red (patent.propose, transcribe.pdf, acceptance not yet walked), so the diff would ripple far outside the pii gate this round exists to fix. deferred for dirt; fulcrum F3 in the route records the call.
