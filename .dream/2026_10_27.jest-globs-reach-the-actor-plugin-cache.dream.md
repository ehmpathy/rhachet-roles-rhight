# 🌙 dream: jest's test globs reach the local claude plugin cache under the actor dir

kind: reseed · owner: declapract-typescript-ehmpathy (the jest config practice) · caught 2026-10-27

## .the cue that fired

`THOROUGH=1 npm run test:unit` failed 6 suites, every one under `.agent/.actors/actor.via.repo=ambient/brain/.claude/plugins/marketplaces/…/tests/*.test.ts` (`Cannot find module 'claude-code/testing'`). that dir is claude code's plugin cache: gitignored, host-local, absent in CI.

## .the gap, precisely

the practice's `testMatch` (`**/*.test.ts`, minus acceptance, integration, `.yalc`) has no exclude for `.agent/.actors/**`. the actor layout that rhachet 1.50 introduced puts each brain dir, and so its plugin cache, inside the repo tree. any repo on that layout fails a thorough local run.

## .the shape of the fix

add `'!**/.agent/.actors/**'` to `testMatch` in the unit, integration, and acceptance jest configs of the practice, then let each repo pick it up via `declapract upgrade`.

## .why it is not done in this round

the jest configs are owned by the declapract practice; a local edit drifts from it and a later upgrade reverts it. this repo's suites pass with the dir excluded on the command line.
