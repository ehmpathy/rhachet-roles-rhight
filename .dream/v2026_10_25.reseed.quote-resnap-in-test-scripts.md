# 🌙 dream: quote $RESNAP in the test scripts so CI stops rewriting snapshots

kind: reseed (the scripts likely come from the ehmpathy declapract practice) · owner: mechanic · caught 2026-10-25

## .the cue that fired
shard 1 of run 40240422679 (PR #41) printed `Snapshots: 3 updated` in CI, with no RESNAP set.

## .the gap, precisely
`package.json` test:unit, test:integration, test:acceptance:locally, test:acceptance all carry
`$([ -n $RESNAP ] && echo '--updateSnapshot')`. with RESNAP unset this collapses to `[ -n ]`, which is
true, so every run passes `--updateSnapshot`. a mismatched snapshot is rewritten, never failed.
- proof: `unset RESNAP; echo "[$([ -n $RESNAP ] && echo x)]"` prints `[x]`; quoted prints `[]`
- present on origin/main (4 hits); run 40232751478 also shows `3 updated`

## .the shape of the fix
quote both: `[ -n "$RESNAP" ]` and `[ -z "$THOROUGH" ]`, in all four scripts. clamp: a test that runs the
script expansion with RESNAP unset and asserts no `--updateSnapshot`. expect latent snapshot reds to
surface once fixed (the rewrites have hidden them); resnap each one deliberately, by review.
reseed upstream in the declapract practice so every ehmpathy repo gets it.

## .why it is not done in this round
quota spent (0 left, director order), and package.json holds an uncommitted dependency bump that must
stay out of #41. safe, but not clean: it ripples into every repo the practice manages.
