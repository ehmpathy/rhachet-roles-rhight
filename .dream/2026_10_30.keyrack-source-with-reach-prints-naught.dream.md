# 🌙 dream: `rhx keyrack source --reach` emits the export, or fails loud

- kind: reseed (ehmpathy/rhachet)
- owner: rhachet keyrack
- caught 2026-10-30

## .the cue that fired
`rhx keyrack source --owner ehmpath --env prep --key BRAINS_AUTH__OF__CLAUDE_CODE_OAUTH_TOKEN --org @all --reach owl@ehmpath.com` exited 0 with empty stdout and empty stderr, while `rhx keyrack get … --reach owl@ehmpath.com --value` returned the 108-char token. an `eval "$(… source …)"` then exports naught and reports success.

## .the gap, precisely
`source` with `--reach` on a reach-addressed pool key prints no export statement and no error: a silent half-success.

## .the shape of the fix
- emit `export BRAINS_AUTH__OF__CLAUDE_CODE_OAUTH_TOKEN=…` for the named reach, as `get --value` resolves it
- or, if source deliberately refuses reach keys, exit 2 with a `ConstraintError` that names `get --reach --value` as the path
- clamp: a reach pool key sourced by reach; assert the export line, or the named refusal

## .why it is not done in this round
the fix belongs to ehmpathy/rhachet, not this repo.
