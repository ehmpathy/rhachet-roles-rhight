# define.boundary.transferable-loyalty-point-flips-toward-stored-value

## .what

a loyalty point earned by, and locked to, one account reads as a **promotional record** — a discount
the issuer owes that one holder. the moment the point can be **transferred** person-to-person — sent,
gifted, sold, or moved to another holder's account — it starts to read as a **stored-value /
prepaid-access instrument**: a unit of value that circulates on its own. transferability is a core
**hallmark** the money-services definitions name, so that trait pushes the same point across a line
into a more heavily regulated character (prepaid access / money-transmission), and out of the
loyalty-record posture that keeps it clear of stored-value, MT, and escheat.

the point stays on the loyalty side while it is **non-transferable and issuer-mediated**; it flips
toward stored value when it becomes **freely transferable** as a bearer-like unit.

## .why

- the federal prepaid-access / stored-value definitions turn on value that can be **retrieved or
  transferred** — transferability is written into the definition itself. a transferable balance
  therefore fits the instrument the rule was written to reach.
- a **non-transferable** point can only ever settle back to the one account that earned it — it is a
  discount the issuer owes a single holder, not an instrument that circulates. that keeps it a
  promotional record.
- the loyalty-record escheat exclusion and the debt characterization both rest on the point as a
  contribution-earned obligation to **one** holder. a transferable point behaves like a cash
  equivalent that can move between parties — which is exactly what the exclusion's "or otherwise
  monetized" carve-back and the stored-value definition are built to catch.

## the hallmark — value that can be transferred

FinCEN's prepaid-access definition names transferability on the face of the rule:

> "Access to funds or the value of funds that have been paid in advance and can be retrieved or
> transferred at some point in the future through an electronic device or vehicle, such as a card,
> code, electronic serial number, mobile identification number, or personal identification number."

**source**: [31 CFR § 1010.100 (prepaid access)](https://www.law.cornell.edu/cfr/text/31/1010.100)

the predecessor "stored value" definition carried the same transferability hallmark — value
"retrievable and transferable electronically." the two essential traits both definitions share are
**retrievability** and **transferability**.

**source**: [Bank Secrecy Act — Prepaid Access Final Rule (Federal Register)](https://www.federalregister.gov/documents/2011/07/29/2011-19116/bank-secrecy-act-regulations-definitions-and-other-regulations-relating-to-prepaid-access)

a point that a holder can move to another person is value that "can be ... transferred" — the exact
shape the definition describes.

---

## why person-to-person transfer is the flip, not in-loop redemption

not every "transfer" moves the point toward stored value. the distinction is **who ends up with the
value**:

- **in-loop redemption** (the holder spends the point on their own discount) settles the point back
  to the issuer — no new holder, no circulation. stays a loyalty record.
- **issuer-mediated re-grant** (the issuer, at the earner's direction, issues a fresh promotional
  benefit to a second account under program terms) can preserve the loyalty character if the value is
  **never a bearer unit in the holder's hands** and only ever moves as an issuer-controlled grant.
- **free person-to-person transfer** (the holder hands the point to another holder as a portable unit
  they can then spend or pass on) is the flip — the point now circulates as value independent of the
  account that earned it.

the money-transmission concern rides alongside: once value moves **from one person ... to another**,
the two-element money-transmission test is in view.

> "the acceptance of currency, funds, or other value that substitutes for currency from one person
> and the transmission of currency, funds, or other value that substitutes for currency to another
> location or person by any means"

**source**: [31 CFR § 1010.100 (money transmission)](https://www.law.cornell.edu/cfr/text/31/1010.100)

## the redline

| loyalty side (promotional record) | the line | stored-value side (regulated instrument) |
|-----------------------------------|----------|------------------------------------------|
| point is **non-transferable** — locked to the account that earned it | "can it be retrieved or transferred?" | point is **freely transferable** person-to-person as a portable unit |
| redeems **in-loop** to the earner's own discount | | circulates between holders independent of the earning account |
| any re-grant is **issuer-mediated** under program terms, never a bearer unit | | the holder hands over value that the recipient can spend or pass on |

**the separator:** can the point become a **portable unit of value in a holder's hands** that moves
to another person? if it can only ever settle to the account that earned it (or move as an
issuer-controlled grant that is never a bearer unit), it stays a loyalty record. if a holder can hand
it to another holder as spendable value, it flips toward stored value.

---

## where a "gift" feature stays on the loyalty side vs flips

a "send some to a family member" feature falls on either side of the line by its mechanics:

- **stays a loyalty record** where it is an **issuer-mediated grant**: the point is never a portable
  unit the holder controls and hands over; the issuer issues a **fresh promotional benefit** to the
  recipient account under program terms, at the earner's request — value the issuer grants, not value
  the holder moves — and the benefit remains non-cashable and non-transferable in the recipient's
  hands, so it never becomes a unit that circulates.
- **flips toward stored value** where the holder can freely move a portable unit to another holder as
  spendable value — that is a bearer transfer, and it re-opens prepaid-access, money-transmission, and
  escheat analysis.

the two feature shapes carry the same label ("gift") but different legal characters; whether a given
feature is a grant or a bearer transfer is a fact question about who controls a portable unit.

---

## the honest gap

- **the mediated-grant line is fact-sensitive.** whether an issuer-controlled re-grant stays a
  loyalty record or is treated as a transferable instrument in substance depends on the exact
  mechanics (does the holder ever control a bearer unit?), and is counsel-confirmable.
- **per-state divergence** — state money-transmitter and stored-value regimes, and any closed-loop
  exemptions, differ by state; the federal prepaid-access definition is cited as the clearest
  articulation of the transferability hallmark, not the only regime. confirm each state of operation.

## key takeaways

| question | answer |
|----------|--------|
| what flips a loyalty point toward stored value? | free **person-to-person transferability** as a portable unit |
| why does transferability matter? | it is a named hallmark of the prepaid-access / stored-value definition |
| does in-loop redemption flip it? | no — it settles back to the issuer, no new holder |
| can a "gift to family" feature stay on the loyalty side? | only as an **issuer-mediated grant** that is never a bearer unit and stays non-cashable |
| what else does a transferable point re-open? | prepaid access, money-transmission, and escheat analysis |
