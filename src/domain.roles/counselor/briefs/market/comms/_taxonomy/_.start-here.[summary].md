## ⭐ the point to carry away first

the four questions do **not** collapse into one. **four different defeats exist**, and a solution to
one does not carry to the others — the single most common misread in the subject.

| the track | what defeats it | what does **NOT** |
|-----------|-----------------|-------------------|
| **`§ 227(b)`** — autodialer / prerecorded voice to a wireless number | **prior express written consent**, tied to that number, still producible | a suppression program |
| **`§ 227(c)`** — the do-not-call track | a **suppression program**, established *and* implemented with due care | ⛔ **consent — this track's statutory defense has no consent element at all** |
| **the multiplier** — class aggregation, where the dollars are | an **arbitration clause + class waiver** whose formation reaches the claimant | a perfect consent record |
| **the cost** of any of the above | **cover bought before the claim**, verified on the grant | a standard CGL — it names the TCPA in its exclusion |

⚠️ **row 2 reads two ways and only one is right.** a sender with flawless per-number written consent
is **still exposed** on `§ 227(c)`, because that subsection turns on objections, not agreement.

## ⭐ the floor we found — six layers, each with its authority

this is the minimum stack the research supports, assembled in one place. it is the answer to the four
defeats above: layers 1–2 for `§ 227(b)`, layers 3–4 for `§ 227(c)`, layer 5 for the multiplier,
layer 6 for the cost.

⛔ **a floor, not a guarantee.** the research found **no sure mechanism** — four tracks, each defeated
by a different layer, plus two gaps that stay open even when all six stand. a counter-example is the
most valuable reply this floor can receive.

⚠️ **not ranked, on purpose.** the six are listed, not ordered — a sequence is an appetite statement
that depends on served states and channel mix, and the sources compel none. derive the order from a
real footprint, not from ours.

| # | the layer | its authority | full detail |
|---|-----------|---------------|-------------|
| **1** | prior express written consent, **per number** — signed, names the number, no purchase condition (e-signature counts). defeats `§ 227(b)`; survived the 2025 vacatur | `47 C.F.R. § 64.1200(f)(9)` | `../ref.tcpa-consent-elements.[ref].md` · `../hazard.unprovable-consent-record.[hazard].md` |
| **2** | revocation honored **≤ 10 business days**, by any reasonable method — no `STOP`-only exclusive channel. ⚠️ FL adds a 15-day cure as a condition precedent; build to the strictest served-state clock | `§ 64.1200(a)(10)` · `Fla. Stat. § 501.059(10)(c)` | `../ref.mini-tcpa-five-state.[ref].md` |
| **3** | ⭐ the internal suppression program, **actually run** — the six minimum standards. the layer consent does **not** reach, and the only one the statute names a defense for. a vendor list does not outsource the liability | `§ 64.1200(d)` | `../ref.dnc-suppression-program.[ref].md` |
| **4** | registry scrub **no older than 31 days**, records kept — the record is part of the standard, not evidence of it | `§ 64.1200(c)(2)(i)` | `../ref.dnc-suppression-program.[ref].md` |
| **5** | an arbitration clause whose **formation** reaches the claimant — the layer that governs the multiplier. the axis is conspicuity of assent, **not** customer status | `Soliman` · `Knutson` | `../define.boundary.formation-not-customer-status-is-the-axis.[lesson].md` |
| **6** | cover verified **before** the claim — the standard CGL names the TCPA in its exclusion; read the grant's nouns (information vs contact); a cyber endorsement is not a fallback | ISO `CG 00 01 04 13` · `Yahoo` · `Bochenek` | the insurer hazard, below |

⛔ **two gaps stay open even when all six stand** — the reason it is a floor and not a peak:

- **`§ 227(c)(5)`'s "due care" is unconstrued** — the layer-3 defense has a named statutory shelter,
  but **no read decision applies its standard**, so what a court demands of the program is unknown
- **California requires a live, unrecorded voice announcement mid-call** for a prerecorded message
  (`Cal. Pub. Util. Code § 2874`) — **no written record satisfies it**, so a stack built to the
  federal written-consent standard is compliant federally and can still fail in California on the
  consent step itself. ⚠️ **Indiana is not the same gap:** it states a live-operator route
  (`Ind. Code § 24-5-14-5`) as an **alternative** to ordinary consent, so a valid written consent
  record still reaches Indiana. see `../ref.mini-tcpa-five-state.[ref].md`

the full treatment — each layer's checklist, the operative quotes, the traps, and all seven named
gaps — is in `../tactic.the-discovered-floor-against-a-tcpa-claim.[lesson].md`.

## ⭐ the line between the terrain and the build

the briefs draw one line on purpose, and a reader who misses it will look for a design that is not
there.

all the set states is **terrain** — the facts, stated both-sides, cited to the source. an actor
absorbs it. the **applied layer** on top — a specific consent-record schema, a specific STOP handler,
*which* safe harbor a program builds toward, *how* the opt-in form → capture → suppression →
production is sequenced — is a **business and legal decision**, not a fact, and the set states none of
it. a program set down is a program designed, and that is counsel's call against a real fact pattern.

| the set states, as **facts** (the terrain) | the actor builds, with counsel (the applied layer) |
|---------------------------------------------|----------------------------------------------------|
| the elements of consent — `../ref.tcpa-consent-elements.[ref].md` | the field list and capture flow that carries them |
| the record's required contents + retention floor — `../hazard.unprovable-consent-record.[hazard].md` | the schema, the store, the per-number production query |
| the six DNC minimum standards + two safe harbors — `../ref.dnc-suppression-program.[ref].md` | which safe harbor the program earns, and the suppression pipeline that earns it |
| the 61 todos the lines force — `../floor.mustcants.[lesson].md` | the program that closes each one — done when the artifact can be produced |
