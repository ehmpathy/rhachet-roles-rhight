# inventory.of=tax-trigger.tax=sales.state=utah

## .answer

**yes, SaaS is taxable** — license fees for remotely accessed **prewritten** software used in Utah are taxable (custom software is not). a remote seller must collect once its gross revenue from Utah sales **exceeds $100,000 in the previous or current calendar year**; the 200-transaction test ended July 1, 2025.

## .the threshold

> "Utah requires a remote seller to collect and pay Utah sales tax if, in either the previous or the current calendar year, the remote seller receives a gross revenue of more than $100,000 from the sale of tangible personal property, any product transferred electronically, or services for storage, use, or consumption in Utah."
>
> — Utah State Tax Commission, *Remote (Out-of-State) Sellers* page (pulled 2026-10-05)

> "Remotely accessed software includes hosted software, application service provider (ASP) software, software-as-a-service (SAAS), and cloud computing applications."
>
> — Utah Publication 64 (Rev. 05/12), § Remotely Accessed Software

> "License fees for remotely accessed custom software are not taxable."
>
> — same

## .details

| item | value |
|---|---|
| figure | > $100,000 gross revenue |
| which sales count | sales of tangible goods, products transferred electronically, and services for use in Utah |
| period | previous or current calendar year |
| effective | $100,000-only test from July 1, 2025 (200 transactions before) |
| physical presence also triggers | yes — the test is for remote (out-of-state) sellers |
| SaaS rule | prewritten remotely accessed software taxable *"if the purchased software is used in Utah"* (Pub 64) |
