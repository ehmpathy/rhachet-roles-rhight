# inventory.of=tax-trigger.tax=sales.state=mississippi

## .answer

**partly — remotely accessed SaaS is not taxable to a remote seller**: software on an out-of-state server accessible only via the Internet is outside the use tax, though software sales and license fees are taxable. a remote seller must register and collect **seller's use tax** once its **sales into Mississippi exceed $250,000 for the prior twelve months** (no transaction count).

## .the threshold

> "Sellers who lack physical presence nexus in Mississippi but who are purposefully or systematically exploiting the Mississippi market have a substantial economic presence for … use tax purposes if their sales into the state exceed $250,000 for the prior twelve months."
>
> — Miss. Admin. Code 35.IV.3.09, rule 100

> "Effective July 1, 2018, businesses located out of the state that have sales into the state of Mississippi that exceed $250,000 over any twelve month period are considered to have substantial economic presence in the state and are required to register with the Mississippi Department of Revenue in order to collect and remit tax."
>
> — DOR, *Business Tax FAQs*

> "However, software maintained on a server located outside the state and accessible for use only via the Internet is not taxable."
>
> — Miss. Admin. Code 35.IV.5.06, rule 300 (use tax)

## .details

| item | value |
|---|---|
| figure | > $250,000 sales into Mississippi |
| which sales count | sales into the state; the rule does not limit them to taxable sales |
| period | the prior twelve months / any twelve-month period |
| effective | July 1, 2018 (FAQ); the rule *"applies to all transactions occurring on or after December 1, 2017"* (rule 103) |
| physical presence also triggers | yes — property, employees, or agents in Mississippi |
