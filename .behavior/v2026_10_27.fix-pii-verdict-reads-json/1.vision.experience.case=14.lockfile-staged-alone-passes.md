# case=14 — a lockfile staged alone passes (C16 · happy · critipath)

## narrative

after a merge, a committer runs `pnpm install` and stages only `pnpm-lock.yaml`. the gate never sends a lockfile to the brain: it holds names and hashes, and it alone can overflow the review window.

the gate splits the lockfile off before its empty check. no file is left to review, so it asks no brain, names the cut path, and passes. the same holds for a dir symlink staged alone, which `rhx review` never takes as a target.

## [tn]

```
given('[case14] a staged set made only of cut paths')
  when('[t0] only pnpm-lock.yaml is staged')
    then('it asks no brain')
    then('it shows files: 0 and names the lockfile under skipped')
    then('it exits 0')
  when('[t1] only a dir symlink is staged')
    then('it names the dir under skipped and exits 0')
```
