# case=5 — an absent verdict file fails closed (C8 · sharp · critipath)

## narrative

a clone runs `git commit` on a brief edit. a few seconds later the commit is refused: `🦅 the review could not run`. it reads on. the tree says this is a MALFUNCTION, not a detected leak — the diff was never examined. under its reviewer it finds the cause: `no verdict json at .log/bhrain/review/<ts>/output.response.json`. so the problem is the review tool, not its diff: the run printed its summary, even a stray `0 blockers`, and then left no verdict file. the gate would not take the summary's word, and retried once before it gave up. the clone checks the bhrain version and finds a release that renamed the artifact. it files the fix against the gate, not its brief.

## [tn]

```
given('[case5] rhx review prints logs: but writes no output.response.json')
  when('[t0] the gate runs')
    then('it retries once')
    then('it scores the reviewer MALFUNCTION — never 0/0')
    then('it exits 1 and says the diff was never examined')
    then('its cause line names the absent json path')
```
