# case=1 — a clean commit passes (C1 · happy · critipath)

## narrative

a clone stages a brief edit and runs `git commit`. the regex pass finds no shape. the brain pass runs `rhx review`, which writes `.log/bhrain/review/<ts>/output.response.json` with empty `blockers` and `nitpicks`. the gate reads that file, counts 0/0, prints `✅ <brain> — clean (0 nitpick(s))`, and exits 0. the commit lands. the clone never thinks about the gate.

the next day the same clone commits a brief the brain finds two style nits in. the json carries `"blockers": []` and two entries in `nitpicks`. the gate prints `✅ <brain> — clean (2 nitpick(s))` and still exits 0. nitpicks inform; only blockers decide.

## [tn]

```
given('[case1] a clean staged diff')
  when('[t0] git commit fires the pii gate')
    then('rhx review writes output.response.json { blockers: [], nitpicks: [] }')
    then('the gate reads 0 blockers, 0 nitpicks from that json')
    then('it exits 0 and the commit lands')
  when('[t1] the json carries 0 blockers and 2 nitpicks')
    then('the gate prints ✅ <brain> — clean (2 nitpick(s))')
    then('it exits 0 — nitpicks never decide')
```
