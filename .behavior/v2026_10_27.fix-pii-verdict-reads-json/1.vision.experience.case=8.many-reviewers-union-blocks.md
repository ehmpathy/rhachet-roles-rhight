# case=8 — one block among many reviewers blocks the commit (M2 · sharp · critipath)

## narrative

a maintainer runs the gate with three brains for a sensitive change: `--brain a --brain b --brain c`. each runs its own `rhx review` in its own process and log dir, and each verdict is read off its own json. brain a finds one blocker. brain b's json is clean. brain c's run wrote no json, so it is a malfunction. the gate folds them: a block outranks a malfunction, and a malfunction outranks a pass. so it prints `🚨 a — 1 blocker(s), 0 nitpick(s)`, `✅ b — clean (0 nitpick(s))`, `💥 c — verdict unreadable`, then `results are UNIONED: any blocker from any reviewer blocks` and the report files `.pii-review.<slug>.md`, and exits 2. the fix-the-diff answer comes first, because the leak is real whatever c would have said.

## [tn]

```
given('[case8] three reviewers: a json with 1 blocker, b json clean, c json absent')
  when('[t0] the gate runs')
    then('each reviewer is read from its own output.response.json')
    then('the fold yields block, because one block outranks a malfunction and a pass')
    then('it lists all three verdicts and exits 2')
```
