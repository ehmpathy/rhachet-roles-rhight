# case=9 — a clean reviewer cannot vouch for one that never ran (M2b · sharp · critipath)

## narrative

a maintainer commits under two brains. brain a reads its json and finds nothing. brain b's run dies before it writes its verdict. the commit is refused: `🦅 the review could not run`. the tree lists `✅ a — clean (0 nitpick(s))` and `💥 b — verdict unreadable`, then b's cause line. the maintainer learns that half the review never happened, so a's clean is not the whole answer: b might have seen what a missed. they fix b's cause (unlock, refill a key, rerun) and commit again; both reviewers read clean and the commit lands.

## [tn]

```
given('[case9] two reviewers: a json clean, b json absent')
  when('[t0] the gate runs')
    then('the fold yields malfunction — a clean never outranks an unread verdict')
    then('it lists ✅ a and 💥 b with b's cause line, and exits 1')
  when('[t1] b's cause is fixed and the commit is retried')
    then('both read clean and it exits 0')
```
