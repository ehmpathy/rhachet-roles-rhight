# case=4 — a zero in a staged path cannot hide a real leak (C7 · sharp · critipath)

## narrative

the mirror of case 2, and the worse half: a staged path like `blocker/0.notes.md` prints ahead of a real `2 blockers` summary. today the gate reads `0` and passes — it **fails open**, and a pii leak lands in history where it can never be rotated out.

after the cure, the gate reads `.blockers | length` = 2 off the json, prints `🚨 <brain> — 2 blocker(s)`, names `.pii-review.<slug>.md`, the report that lists each finding with its location, and exits 2. the human opens the report, redacts the two values, and commits again. stdout cannot lower the count any more than it can raise it.

## [tn]

```
given('[case4] a staged path blocker/0.x.md, printed ahead of the summary')
  given('the reviewer json carries 2 blockers')
  when('[t0] the gate runs')
    then('it reads 2 blockers — the path digit is not a verdict')
    then('it prints 🚨 <brain> — 2 blocker(s) and names the report to read')
    then('it exits 2')
  when('[t1] the human redacts both values and commits again')
    then('the json carries 0 blockers and the commit lands')
```
