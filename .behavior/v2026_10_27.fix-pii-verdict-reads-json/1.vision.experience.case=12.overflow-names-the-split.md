# case=12 — an overflow names the split (C14 · sharp · critipath)

## narrative

a committer stages a change too large for one review: many source files and their tests at once. `rhx review` refuses: the prompt exceeds 75% of the brain's context window, and it prints no `logs:` line.

the gate reads the refusal header, asks once (a second ask returns the same refusal), and blocks with a cause and a fix that fit: the staged diff is too large for one review; split it into smaller commits. no keyrack hint appears.

## [tn]

```
given('[case12] a staged diff over the review window')
  when('[t0] the gate runs')
    then('it asks the reviewer once')
    then('it names the overflow as the cause')
    then('it says to split the commit, and names no keyrack step')
    then('it exits 1')
```
