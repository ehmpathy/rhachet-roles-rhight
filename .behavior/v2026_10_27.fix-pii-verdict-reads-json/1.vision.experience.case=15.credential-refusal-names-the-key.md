# case=15 — a credential refusal names the key (C17 · sharp · critipath)

## narrative

a committer on a fresh box stages a letter. the box holds no prep key for the review brain. `rhx review` refuses before any brain call: it prints `✋ ConstraintError: ANTHROPIC_API_KEY not found in keyrack (owner ehmpath, env prep)` and no `logs:` line.

the gate asks once, since a missing key does not fix itself on a retry. it blocks as a malfunction, not a leak. the cause line names the refusal as `rhx review refused: <message>`, with no doubled class label. the hint gives the exact recovery: unlock prep, or have a human fill the key with `rhx keyrack set`. the same holds for the openrouter brain, which names its own key.

## [tn]

```
given('[case34] a review that refuses on an absent brain key')
  when('[t0] the anthropic brain has no key')
    then('it asks rhx review once')
    then('the cause reads rhx review refused: ANTHROPIC_API_KEY not found in keyrack')
    then('the hint names rhx keyrack set for the key')
    then('it exits 1')
  when('[t1] the openrouter brain has no key')
    then('the cause and hint name OPENROUTER_API_KEY')
```
