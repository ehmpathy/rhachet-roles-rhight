# case=7 — a verdict file of the wrong shape fails closed (C10 · sharp · critipath)

## narrative

the morning after a bhrain release, every commit in the org is refused: `🦅 the review could not run`. a maintainer reads the cause line: `verdict json .blockers is number, not an array, at <path>` — the release now writes a count where the gate expects a list. the message tells them three things at once: the review ran, its shape changed, and the gate refused to guess. a quiet guess would have been worse: `jq '.blockers | length'` on a null reads 0, which would have waved through every leak until someone noticed. the maintainer updates the gate's reader, and commits resume. the block was loud, and it was the tool's fault, never a diff's.

## [tn]

```
given('[case7] output.response.json is { "blockers": 2, "nitpicks": null }')
  when('[t0] the gate runs')
    then('the array type check fails, and the gate retries once')
    then('it scores the reviewer MALFUNCTION — it never reads length of a non-array')
```
