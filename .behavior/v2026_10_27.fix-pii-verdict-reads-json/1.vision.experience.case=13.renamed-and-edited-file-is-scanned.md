# case=13 — a renamed and edited file is scanned (C15 · sharp · critipath)

## narrative

a committer runs `git mv notes.md moved.md`, adds a line that holds an SSN, and stages it. git reports the change as a rename (`R`). both scanners listed files with `--diff-filter=ACM`, so the moved file fell out of the list, and the commit passed unscanned.

the scanners list `ACMR`. the moved file's new path is scanned, the regex layer catches the SSN, and the hook blocks at exit 2 with the value masked.

## [tn]

```
given('[case13] a staged rename whose edit adds an SSN')
  when('[t0] the hook runs')
    then('git reports the change as R')
    then('it exits 2 with ConstraintError: the PII scan blocked the commit')
    then('it never echoes the value')
```
