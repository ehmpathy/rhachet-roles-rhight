# reason: rhachet-brains-fireworksai@0.1.3

## package
- name: rhachet-brains-fireworksai
- version: 0.1.3
- type: prep

## reason
rhachet-roles-bhrain@0.31.3 defaults its review brain to fireworks/deepseek/v4-flash.
rhachet discoverBrainPackages enrolls a brain ONLY from this repo own package.json deps —
a transitive copy under node_modules is invisible to it. so without this direct dep, every
peer reviewer dies with: BrainChoiceNotFoundError: brain not found: fireworks/deepseek/v4-flash.

the matched FIREWORKS_API_KEY is already declared in .agent/repo=bhrain/role=reviewer/keyrack.yml
and inherited by .agent/keyrack.yml via extends, so the credential side needs no change.
