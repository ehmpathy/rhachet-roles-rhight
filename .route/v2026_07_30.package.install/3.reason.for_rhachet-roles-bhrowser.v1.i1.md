# reason: rhachet-roles-bhrowser@0.1.0

## package
- name: rhachet-roles-bhrowser
- version: 0.1.0
- type: prep

## reason
`rule.require.bhrowser-citations` makes a real-browser capture the only acceptable provenance for a
quoted citation. this package supplies the `browser.start` / `browser.action` / `browser.snapshot.*`
skills that rule depends on, so the rule is unenforceable without it.
